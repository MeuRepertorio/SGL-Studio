# SGL — Signals Studio

Um estúdio digital para acompanhar o desenvolvimento da marca streetwear **SGL**. Não é loja virtual nem representa lançamentos confirmados.

## Módulos
- Identidade, manifesto e processo de criação.
- Quadro de iniciativas: adição, edição, exclusão, pesquisa e filtros por frente e etapa.
- Briefing criativo interativo.
- Diário, exportação e importação de backup JSON.
- Interface responsiva e animações, com suporte a `prefers-reduced-motion`.

## Privacidade
O repositório pode ser público. Notas e alterações feitas pelos visitantes são gravadas **apenas no localStorage do navegador**. Não são publicadas no repositório nem compartilhadas entre aparelhos. Evite guardar informação confidencial num navegador compartilhado.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Observação
Itens iniciais do quadro são **sugestões de planejamento**, e não o histórico real da SGL. Dados podem ser atualizados por quem usar o navegador.


## Integração Abalion

Este site inclui `assets/abalion-bridge.js`, que lê `abalion/sections.json` e exibe novas páginas criadas via central Abalion (depois da implantação do GitHub Actions e GitHub Pages). O catálogo está vazio por padrão; nenhuma alteração remota ocorre sem confirmação autorizada.
